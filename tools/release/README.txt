Absolver Pak Editor
===================

Requirements
------------

* A legal Steam copy of Absolver.
* UnrealPak.exe from Unreal Engine 4.18, configured in Settings. It is needed to extract and build paks.

Quick start
-----------

1. Run AbsolverModTool.Gui.exe.
2. Open Settings and set the game Paks folder plus UnrealPak.exe.
3. Choose Extract Game Files... and select an empty folder.
4. Edit assets in Data Editor, then choose Finalize... to make an override pak.

To edit an existing mod, choose Load Mod Pak..., inspect it, then choose Open for editing. The original pak is not changed.

The tool contains no game assets. See THIRD-PARTY-NOTICES.txt and licenses\ for credits and licenses.
